# Trendora starter website

This is a responsive, single-page website starter for Trendora.

## Preview
Open `index.html` in a web browser.

## Before publishing
- Replace the placeholder contact email `hello@yourdomain.com`.
- Replace the sample article cards with researched, original articles and real article pages.
- Connect the newsletter form to a newsletter provider; it is currently a visual demo only.
- Add Privacy Policy, Terms, and Contact pages.
- Choose and register an available domain name.
- Publish using a hosting provider such as GitHub Pages, Netlify, or your chosen web host.
- Add the site to Google Search Console and submit a sitemap after publishing.

This folder is a front-end starter. It is not yet hosted publicly and does not include a content management system or backend.
